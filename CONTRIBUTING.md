# Contributing to Aurora

Thanks for wanting to help. Aurora is free to use, but the app is **not open source** — its source lives in a private repository.

## What is welcome

- **Bug reports** with the platform, version and steps to reproduce
- **Install help** for Windows, Android, iPhone, Mac and Linux
- **Feature ideas** that explain the problem before the solution
- **Website fixes** — typos, broken links, accessibility issues in `aurora/`

Use the [issue forms](https://github.com/BannedVariable/BannedVariable.github.io/issues/new/choose) so reports arrive with the details needed to act on them. The [FAQ](https://bannedvariable.github.io/aurora/#faq) answers the common install questions.

## What is not

- Pull requests that add app features. The app's source is not here, so there is nothing to merge them into.
- Requests for the app's source code, build scripts or signing keys.
- Public disclosure of security problems. Use [private vulnerability reporting](https://github.com/BannedVariable/BannedVariable.github.io/security/advisories/new) instead.

## Website changes

This repository is the public website and release home. Small fixes to `aurora/` are welcome if they do not change the product's behaviour. Open an issue first for anything larger, and keep the site static: it is served by GitHub Pages with no build step.

## Before you post

Remove passwords, account tokens, private files and personal information from screenshots, logs and recordings. Test with your own account and devices only.
