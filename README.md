# bannedvariable.github.io

Public website for [Aurora](https://github.com/BannedVariable/aurora).

- `aurora/` is served at https://bannedvariable.github.io/aurora/
- `aurora/auth.html` is the Google sign-in return page used by the desktop and mobile apps.
- The repository root redirects to `/aurora/`.

GitHub Pages publishes the repository root from `main`. This repository is public on purpose; do not add
private keys or service credentials.
